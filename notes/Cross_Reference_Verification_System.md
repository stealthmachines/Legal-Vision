# CROSS-REFERENCE VERIFICATION SYSTEM

## Cross-Reference Types Found in 11 Am Jur:
1. **Internal** - References to other sections within the same volume
   - "§ 114. See § 115 infra." (forward reference)
   - "See § 114 supra." (backward reference)
   
2. **Inter-Volume** - References to other volumes
   - "See Volume 1, § 23"
   - "See 11 Am. Jur. 2d, Commerce, § 63"

3. **Related Topics** - Cross-references to adjacent subjects
   - "See also Police Power, supra"
   - "See Constitutional Limitations, infra"

4. **See/See Also/But See**
   - **See** - Primary reference to related authority
   - **See Also** - Additional supporting material
   - **But See** - Contrary or limiting authority
   - **But See Also** - Additional contrary material

## Verification Strategy:
As we transcribe each image, we:
1. Scan for all § references
2. Check if referenced sections exist in our transcription
3. Verify section number sequences are logical
4. Flag any missing or out-of-sequence sections
5. Use existing transcriptions to correct new OCR errors

## Cross-Reference Patterns to Expect:
- Section numbers generally increase throughout the volume
- Commerce sections: §§ 63-78 (Commerce Clause)
- Police Power: §§ 245-304
- Fundamental Rights: §§ 308-346
- Constitutional Limitations: §§ 347-382

## Self-Correction Mechanism:
If we find a reference to § 120 but § 120 hasn't been transcribed yet:
1. Note it as "pending"
2. When we reach that section, verify the reference exists
3. If reference doesn't exist, flag as potential OCR error
4. Update both transcriptions if corrections needed
